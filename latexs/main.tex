\section{Introduction}
This report documents the workflow and results of the \texttt{GL\_exam.ipynb} notebook,
which addresses a multivariate time series classification task using the PMTSA\_2025 dataset.
The goal is to predict the onset of sepsis in pediatric patients based on clinical time series data.
The dataset is provided as part of the 2025 Predictive Models for Time Series Analysis competition on Kaggle
as provided in the Kaggle competition~\cite{kaggle2025} and originally from PhysioNet~\cite{physionet2019}.
This report is structured in this way: Section \ref{sec:data_exploration} describes how the data is loaded and the main characteristics of the dataset,
Section \ref{sec:data_preprocessing} describes the preprocessing steps applied to the data,
and Section \ref{sec:classification_task} describes the classification task, the models used.
Finally, Section \ref{sec:results} presents the experimental setup and the results obtained from the models and discusses their performance.

\section{Data Exploration}\label{sec:data_exploration}
In this section, we will explore the dataset used in this project. Fist we describe how the data is loaded and the main characteristics of the dataset.
Then we will analyze the data to understand its structure and distribution of missing values.

\subsection{Data Loading}
The dataset is loaded using \texttt{xarray} with a custom backend (\texttt{pyrregular}).
The main data array has the structured shape $(N, C, T)$,
where $N$ is the number of time series samples, $C$ is the number of channels, and $T$ is the number of timestamps.
The data is stored initially as a sparse array for efficiency, and it is converted in a dense form to be used by the predictive models.

\subsection{Data Description}

The dataset used in this project is derived from the 2019 PhysioNet/Computing in Cardiology Challenge..
It consists of multivariate clinical time series data collected from pediatric intensive care unit (PICU) patients.

Each sample corresponds to a single patient stay, represented as a multivariate time series.
The full dataset contains $N=22332$ samples, and it is split into training and test sets,
where the number of samples in the training set is $N_{tr}=20334$, and the number of samples in the test set is $N_{ts}=1998$.
Each sample contains measurements from $C=34$ clinical channels (vital signs, laboratory results, etc.) over a $T=334$ number of timestamps
sampled every hour.
Static variables such as age and gender are also provided for each patient.

The target is a binary label $0$ or $1$ indicating whether the patient developed sepsis during their stay.
The target labels are provided only for the training set.

\subsection{Data Imputation}
After the filtering process, we apply the imputation process to fill the remaining missing values in the training and test sets.
For the training set, we first check if there are samples with any channel completely missing.
For these samples, we fill the missing channels with the mean of the corresponding channel across all samples.
After that, we apply the imputation process to the training dataset using the \texttt{drift} method from \texttt{sktime}'s \texttt{Imputer}.
The \texttt{drift} method is a time series imputer that uses the mean slope of the time series to fill the missing values.
The imputation process is applied to each channel separately, and it is done in a way that respects the temporal order of the data.
Finally we check if there are any remaining missing values in the training set.

\section{Classification Task}\label{sec:classification_task}
After the preprocessing steps, we compare the performance of several machine learning models for the classification task
respect our baseline model, that is a dummy classifier that predicts the majority class.
First we describe the machine learning models used in this project,
then we describe the experimental setup used to train and evaluate the models.

The classification task is a binary classification task,
where the goal is to predict the onset of sepsis in pediatric patients based on clinical time series data.
The accuracy score is not a good metric for imbalanced datasets,
as it can be misleading and does not reflect the true performance of the model.
To evaluate the performance of the models, instead, we use the F1 score as the evaluation metric,
which is the harmonic mean of precision and recall.
The F1 score is a good metric for imbalanced datasets, as it takes into account both false positives and false negatives.
The F1 score indeed is the harmonic mean of precision and recall, and it is defined as:
\begin{equation}
    F1 = 2 \cdot \frac{precision \cdot recall}{precision + recall}
\end{equation}\label{eq:f1}
where precision is the ratio of true positives to the sum of true positives and false positives,
and recall is the ratio of true positives to the sum of true positives and false negatives.

The label of the test set is not provided, to avoid a data leakage and simulate a real-world scenario.

\subsection{Model Tested}
We compare the performance of different models, in particular the Euclidean K-Nearest Neighbors (e-KNN),
the Convolutional Neural Network (CNN), the Randomized Convolutional Kernel Transform (ROCKET),
and the Catch22 features with a Random Forest classifier (Catch\&RF).

We have choosen these models to compare the performance of different approaches for time series classification,
having these models different characteristics. The e-KNN modxel is a distance-based model,
the CNN model is a deep learning model, the ROCKET model is an efficient kernel-based model,
and the Catch\&RF model is a feature-based model.
The e-KNN model is a simple and interpretable model, but it is a lazy learner
because for each sample it computes the distance to all the other samples and it is biased
to the fact that near samples are more similar than far samples.
The CNN model is a fully trainable deep learning model that uses convolutional layers to learn hidden features from the data,
and its complexity is given from the kernel size and the number of filters, interleaved with pooling layers.
The ROCKET model is a kernel-based model that uses a randomized convolutional kernel transform to learn features from the data,
and it is very efficient because it uses a fixed number of kernels and it is not sensitive to the number of samples.
The Catch\&RF model is a feature-based model that first exploit the Catch22 model to extract $22$ meaningful features from the time series transforming
the timeseries dataset in a tabular dataset,
and then it uses a Random Forest classifier to learn the classification task.
The Random Forest classifier is a tree-based model that uses an ensemble of decision trees to learn the classification task, and it is
the state-of-the-art model for tabular data. 

\section{Results}\label{sec:results}
For each model, we perform a grid search to find the best hyperparameters using \texttt{GridSearchCV} from \texttt{scikit-learn}.
We use a stratified $k$-fold cross-validation to evaluate the performance of each model configuration.
Each fold represent a different split of the training set into a training and validation set,
and the F1 score is computed on the validation set.
For each model we select the best configuration based on the F1 score obtained computing the mean F1 score across the $k$ folds.
We used the stratified version of the $k$-fold cross-validation to ensure that each fold has the same distribution of labels as the original dataset
to avoid a bias in the evaluation of the model.

For the e-KNN, the CNN, and the ROCKET models, we use as first operator the standardization of the data.
The standardization is a common preprocessing step for machine learning models,
and it is used to scale the data to have a mean of $0$ and a standard deviation of $1$.
The standardization is applied to each channel separately, and it is done in a way that respects the temporal order of the data.
We applied the standardization using the \texttt{StandardScaler} from \texttt{scikit-learn},
wrapped by the \texttt{TabularToSeriesAdaptor} from \texttt{sktime}.
The \texttt{TabularToSeriesAdaptor} is a transformer that converts the time series data into a tabular format
that is compatible with the \texttt{StandardScaler}.
The satndard scaler operator is the first operator in the pipeline for the e-KNN, CNN, and ROCKET models,
so that the data is standardized before applying the model
during the training and evaluation process in the cross-validation.
For the Catch\&RF model, instead we do not apply the standardization
because the Random Forest classifier is not sensitive to the scale of the data.
